noiosoos — an Android phone that does less

Your phone, with the interesting parts removed.

NoiosoOS is a black-and-white Android launcher and app suite built to hold your attention as little as possible. No icons, no feeds, no colors fighting for your eyes. Just what you came to do.

Get started Source on GitHub

what this is

Most phones are designed to be looked at. NoiosoOS is designed to be looked away from. It's a set of small Android apps — a launcher, a phone dialer, and more coming — that replace the stock ones with something intentionally plain: black background, white text, nothing decorative.

It's not a full custom ROM (yet). Right now it's apps you install like any other, that you can set as your defaults — home screen and phone app — so the boring version is what you see first.

get started

  1. Clone the repository

    Each app lives in its own folder inside the monorepo.

    git clone https://github.com/GaM1ngN0tDev/NoiosoOS.git

  2. Open a folder in Android Studio

    Open NoiosoHome or NoiosoPhone as its own project — File → Open, point it at that folder.

  3. Build and install

    Run it on a device or emulator (minSdk 33). No extra setup, no accounts, no signup.

  4. Set it as default

    In NoiosoHome, press Home and choose it as your launcher. In NoiosoPhone, tap "set as default phone app" on the dial pad.

why

Phones optimize for being opened. This project doesn't — it optimizes for being put back down. If that sounds useful to you, it's free, open source, and yours to change.
